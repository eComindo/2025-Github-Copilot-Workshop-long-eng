# Workshop material

## About

The aim of this workshop is to give participant knowledge and experience working with Github Copilot and Spec-Driven Development.
Participants will work on a project of creating an MVP (Most Viable Product) of a procurement system.

## Syllabus

Within the project, participants will learn about:

1. Context engineering
2. MCP servers (chrome-devtools, Figma)
3. Persistent instructions/system message
4. Token optimization techniques and tools
5. Spec-Driven Development (SDD)
6. Agent skills
7. Git hooks
8. E2E testing and product documentation using Copilot
9. Custom prompts and custom agents
10. SDD framework "OpenSpec"
